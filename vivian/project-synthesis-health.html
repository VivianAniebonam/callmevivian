Portfolio Summary

As IT Implementation & Integration Project Manager at Synthesis Health I led a portfolio of four AI-driven healthcare projects focused on radiology workflow optimization, cloud-native imaging storage, real-time diagnostic decision support, and PACS multitenancy. Responsibilities included technical leadership, stakeholder management, security/compliance oversight, and delivery of CI/CD-enabled deployments.

Across the portfolio I managed cross-functional teams (total 52 IT professionals), collaborated closely with AI engineers and cloud architects, and ensured HIPAA/GDPR compliance while meeting performance targets and budget constraints.

01AI-Powered Radiology Workflow Optimization

Budget: $2.0M
Team: 15 IT professionals
Impact: Reduced diagnostic turnaround by 25%

Led the technical implementation of a Progressive Web App (PWA) that integrates AI algorithms to prioritize imaging studies. Built React.js dashboards for radiologists and implemented Node.js services to handle real-time communication with PACS systems.

Development Experience:
  • React.js dashboards for prioritized case review
  • Node.js services for real-time PWA & PACS integration
  • Worked with AI engineers to integrate models into backend workflows
  • Performed encryption audits to meet HIPAA requirements
Tools & Frameworks: React.js, Node.js, Azure DevOps, IndexedDB, PACS integration
Key problems solved:
  • Delayed diagnosis: Implemented AI triage to flag critical cases automatically.
  • Offline sync failures: Implemented IndexedDB fallbacks to ensure continuity.

02Cloud-Native Imaging Data Repository

Budget: $3.5M
Team: 12 professionals
Impact: Reduced retrieval latency by ~20%

Designed and implemented a secure, cloud-native repository for imaging data with offline support that integrated with the PWA. Implemented PostgreSQL schemas and IndexedDB for offline-first behavior.

Development Experience:
  • PostgreSQL database design and query optimization
  • IndexedDB configuration for offline access
  • CI/CD pipelines using Azure DevOps for database deployments
  • Worked with cloud architects on scalable, compliant infrastructure
Tools & Frameworks: PostgreSQL, IndexedDB, Azure DevOps, JavaScript, Python
Key problems solved:
  • Connectivity gaps: Offline-first design to guarantee access during outages.
  • High latency: Query optimization and caching to lower retrieval times.
